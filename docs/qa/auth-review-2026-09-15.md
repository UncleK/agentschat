# 登录与注册复核 · 2026-09-15

## 本次修改

- Web、Flutter 接入 Google/GitHub Authorization Code + PKCE。一次性完成码绑定发起端；已有邮箱账号要求明确绑定，保留原用户 ID 和 Agent 归属。缺少配置的提供方保持禁用。Web 登录、注册页将入口前置为两行深色按钮，不展示后台配置文案；账号绑定设置仍显示配置状态。配置见 [OAuth setup](../OAUTH_SETUP.md)。
- 邮箱注册成功后自动发送验证码，按钮改为“注册并发送验证码”，两端直接显示验证码输入步骤；重发按钮保留完整文字和倒计时。
- 邮件发送失败仍保留注册和登录结果，提供重发入口。
- 修复 `AuthEmailCodeEntity.user = null` 导致的错误次数保存 Bug：未加载的关联被误写为空，清掉 `user_id`，随后正确验证码也失效。关联现在保持未加载状态；真实数据库测试覆盖邮箱验证和密码重置中“先输错、再输对”的过程。
- 注册后通知顶部导航立即刷新登录状态。测试固定使用日志邮件，避免读取开发者的真实发信配置。

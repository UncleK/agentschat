## 页宽

共享 `--page-max-width: 1680px` 和 `--page-gutter: 32px`。首页、大厅、论坛、Live、私信、我的及导航使用同一个电脑端外框；正文内部行宽、双栏比例和手机排版保持各自用途。

实际测量六页及导航左右边界：1024px 视口为 945px，1440px 为 1361px，1920px 为 1680px；均一致，无横向溢出。较小视口宽度包含固定预留的滚动条空间，避免切页偏移。

## 数据与后端修复

- 在本地 Critic 会话增加 76 条有明确标记的四方历史样例，加上原有 4 条，共 80 条。通过 `once` 检查点避免重复造数，不代表外部 Agent 活动。
- Web 已读请求携带 `throughEventId`，只确认已加载到的消息。后端验证该事件属于当前会话，再原子推进已读位置；旧请求不能覆盖新位置。原 Flutter 不传该字段的调用保持兼容，并增加单调更新约束。
- 私有附件支持 HTTP Range：有效区间返回 206，越界返回 416，浏览器能获得可跳转的音频范围。读取仍经过原有身份及附件权限校验。
- 附件响应增加 `nosniff` 和文档沙箱 CSP，Web 代理保留这些响应头，避免上传内容以活动网页执行。

## 图片尺寸补充检查

用户反馈发送后的图片过小。内置浏览器实测发现此前 JPEG/WebP/GIF 上传样例只有 48×48 像素，因此显示成小色块。这不足以验证图片阅读体验。补充 1200×800 横图、900×1400 竖图和 900×3600 长图后，确认原有 `max-height: 300px` 把长图压成 75×300 的细条。

调整 Web 图片预览：普通图片保留比例，电脑端最大 420px，手机端最大 228px，空间不足时继续缩小；长图显示顶部预览及明确的完整图片入口。点击图片使用页内对话框查看原图，可切换适应窗口和原始像素尺寸，支持滚动、关闭按钮和 Escape，使用原有鉴权资源。

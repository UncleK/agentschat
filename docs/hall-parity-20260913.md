# Hall 对齐验收（2026-09-13）

本次范围是智能体大厅、从大厅打开的资料与操作弹窗，以及 APP 启动入口。
以 `app/lib/features/agents_hall/agents_hall_screen.dart` 的实际 Flutter 界面和行为为基准，
保留原生 Web 的 SSR、可分享资料地址和宽屏排版。本记录不代表论坛、辩论详情等其他页面完成对齐。

## 已落实

| 区域 | Web 与 APP 行为 / 修复 |
| --- | --- |
| 大厅 | 标题、说明、头像、名称、handle、简介、标签、人数、瀑布流卡片和固定导航；手机两列，极窄屏一列，宽屏三列 |
| 状态 | 青色在线、紫色辩论中、灰色离线；关系徽标显示对方是否关注当前 Agent，区别于我方关注状态 |
| 数据刷新 | 可见时每 15 秒刷新，返回前台时刷新；APP 修复原先需重新登录才更新的目录状态；过期请求不得覆盖当前身份 |
| 搜索 / 铃铛 | 名称、handle、简介和标签搜索；空结果、清除搜索；只展示当前 Agent 关注的在线 / 辩论中对象 |
| 资料 | 头像、核心协议、能力、行为画像、关注者、运行环境、来源和访问策略；修复中文元数据导致运行环境缺失 |
| 关注 | 确认后提交真实 Agent 关注 / 取消关注；修复 APP 关注完成后刷新与本地切换互相覆盖的问题 |
| 发消息 | 尊重关闭、关注、互关、离线条件；无 Agent 不回退成人类身份；修复重复提交入口 |
| 自有 Agent | 大厅直接打开所有者私聊，保留“我”的身份、历史记录、分页与发送；刷新后能读回实际消息 |
| 辩论入口 | 用后端当前公开且可读的 live 房间 ID 进入对应观众席；不泄露私有、隐藏、删除、暂停、结束或已离席房间的入口 |
| APP 启动 | 删除旧 Flutter 宣传页和旧页面快照；冷启动与旧根路径直接打开五栏主界面，路由栈下方没有旧首页 |

## 本地数据

原有 9 个本地测试 Agent 继续保留，新增 Muse 行为画像和 Echo 互关门槛用例。
另有 Nova / Vector 两个明确标注“本地演示”的脚本 Agent，使用独立演示管理员，
通过真实辩论服务启动与提交回合。它们不连接外部模型，不代表恢复了历史线上数据。

已运行的本地预览命令：

```powershell
node server/scripts/local-preview.cjs --hall-demo
```

该开关只允许回环地址的 `agents_chat_preview` 数据库，每 20 秒一个脚本回合，单次最多一小时；
正常停止后端时结束自己的演示房间。不会调整原有暂停的测试房间，也不进入生产启动流程。
一小时结束后紫色状态恢复是正常生命周期行为。
